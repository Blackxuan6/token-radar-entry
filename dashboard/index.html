How the board is priced

Every implied value comes from the snapshot's own numbers. No protocol name is special-cased; the same function scores all 289 rows.

implied = TVL × multiple × growth × maturity × breadth
multiple  = category median mcap/TVL among live-token protocols,
            shrunk toward the global median (weight n / (n + 8)),
            clamped to [0.03, 1.50]; no comps → global median
growth    = 1 + clamp(7d change, −50%, +150%) × 0.6
maturity  = 0.55 + min(age, 1095 days) / 1095 × 0.45   (unknown age: 365 days)
breadth   = 1 + min(chains − 1, 9) × 0.02

Category multiples

Median market-cap-to-TVL ratio per category, after shrinkage. Categories with no live-token comps use the global median.

What the board is — and is not

  • Pre-token means the snapshot records no token for the protocol. It does not mean the protocol has no token, and it is not a promise that one is coming.
  • Implied value is a model estimate from the snapshot's numbers, not a price target and not a prediction of any launch.
  • The watchlist is the snapshot's floor: pre-token protocols at $50M TVL or more. The board ranks it plus every rankable pre-token protocol below the floor.
  • Farm plans are generic steps for a protocol's category. They never claim a points program or an airdrop exists; where a step depends on one, it says so and points at the protocol's own page. Costs are estimates.
  • Snapshot: DefiLlama protocols, 2026-11-14. Floor: $50,000,000. 758 protocols scanned, 289 ranked.
